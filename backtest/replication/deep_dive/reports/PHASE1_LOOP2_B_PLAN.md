# Phase 1 final loop, Investigation B: D-1 session stop. Preregistration

*Written 2026-11-25. **Honest ordering:** the real-book D-1 mark-to-market paths (`outputs/phase1/9/B_real_book_mtm.csv`) were computed first as an inspection, and showed one real D-1 stop (NIFTY 2026-09-01, `s_` module, 14:46, 30 orders, liquidating the whole book) and two non-stop D-1 sessions whose minute-close MTM fell below -1.20 lakh (NIFTY 2026-10-06 -1.2177, SENSEX 2026-10-08 -1.2173). Everything below (candidate constant, engine switch, criteria) was fixed **before** any engine result. Experiments `P1-9-B*`. Baselines: frozen B1 (D-1) and D0-C (D0); the frozen constant is L = 1.20 lakh. Evidence: historical reproduction on development cycles. Nothing committed.*

## 1. Two mechanisms that must not be confused
* **Cycle stop (confirmed, `D1-15`):** cumulative mark-to-market since the D-1 open, all modules, minute-close marks.
* **A "session-level" stop:** a threshold on the loss since the **start of each session** (D-1 and D0 separately). In the D-1 session the two windows are identical (the cumulative loss since the D-1 open IS the session loss), so **D-1 data cannot distinguish them**. The D0 study already tested the D0-only scope (loss since the D0 open): F1 <= 0.27, 8-10 false alarms: **rejected**. A session-scope stop is therefore not testable in D-1 and is rejected in D0; recorded, not asserted.

## 2. What is testable: does the cycle-stop rule hold on the D-1 session and does the constant survive the full path?
Full-path real-book test (teacher-forced; labelled), 30 cycles with both logs: path = D-1 session MTM (real fills, minute-close marks) followed by the D0 path of `bl_d0x_mtm.pkl.gz`. A **hit** = first crossing within [stop minute - 1, stop minute] of the real stop (D-1 or D0); a **false alarm** = a crossing with no real stop in that cycle before the end.
| # | Candidate | Definition |
|---|---|---|
| BX0 | current constant | L = 1.20 lakh |
| BX1 | interval-consistent constant | L = 1.25 lakh: the midpoint of the interval (max |min MTM| of any non-stop cycle over the full path, min depth at any real stop] rounded to 0.05; the interval is computed from the data and printed; if it does not contain 1.25 the candidate is dropped |
The two candidates are counted for selection. **Support requires:** all real stops hit and 0 false alarms in the combined D-1 + D0 path of every cycle.

## 3. If BX1 is supported: two follow-ups, each preregistered here
**BE-D0 (promotion of the constant in the D0 engine).** `cycle_stop_rupees = 1.25e5` in D0-C, scored with the unchanged pipeline (mode T OOF, forward A/B, LOCO, integrated mode F). Accepted only if: OOF keys F1 >= 0.4217 - 0.003; legacy lot-level >= 0.4142 - 0.005; no class F1 down by more than 0.02; no cycle's F1 down by more than 0.05; D0 stop-cycle agreement not worse than 8 hits / 3 false (standard D7); forward A/B not lower than before by more than 0.003; risk and determinism unchanged.
**BE-D1 (D-1 session stop in the D-1 engine; new default-off switch).** The D-1 engine has no stop. `cycle_stop_rupees` (default `None` = baseline): every 5 simulated seconds the engine marks its own book (shorts at the live price, wings and lump longs, simulated cash) and, when the cumulative MTM <= -L, **liquidates the whole book** (buy back every short lot, sell every wing/lump long; roles `cycle_stop_*`, module `s_`, validity `DAY` as in the first real stop orders) and halts every new order for the rest of the session. Decision uses only the engine's own state and live prices (no future bar, no real input). Scored under `one_lot_v2` against B1: accepted only if (all): the stop fires in NIFTY 2026-09-01 within +/-2 minutes of the real stop minute (331); false stops <= 2 of the other 31 sessions (the simulated MTM differs from the real one, so false stops are expected and counted); keys F1 (60 s) >= 0.739 - 0.005; strict F1 >= 0.472 - 0.005; legacy lot-level F1 >= 0.6878 - 0.005; scheduled straddles matched >= 2,076; no class F1 down by more than 0.02 (the new `stop` class is scored separately); **no cycle without a stop differs from B1 (orders identical)**. Report: orders prevented, real orders prevented/missed after the stop, orders added, effect on 15:15+ closing activity, buy-backs, wings and portfolio state in the stop cycle, per-cycle consistency.
**Stop rule:** a rejected candidate is archived; no equivalent variant is run. If BX1 is not supported, the constant stays at 1.20 and the contradiction is recorded as an unresolved measurement limit.

## 4. Limits stated in advance
One real D-1 stop only (n = 1) and 11 D0 stops: the constant is an interval estimate from 12 stop events and minute-close marks, not a precise value; the midpoint is a choice inside the interval; in-sample; the real stop uses live prices (minute-close marks are a convention); D-1 session stops cannot be separated from the cycle stop in D-1.
