# M2-E — Visualization catalog

Generated by `tools/m2e_catalog.py` from `reports/m2e_figures/<cycle>/figure_manifest.json`. Every figure is drawn **only** from files in `reports/m2e_data/<cycle>/` and writes the plotted values to a sibling CSV (data-to-chart link). All times are IST (UTC+05:30). Historical marks are missing (source absent): no mark, no interpolated price, no unrealized P&L appears anywhere.

## Visual language

| Treatment | Meaning |
|---|---|
| Solid fill, solid outline | OBSERVED fact (fills, parents, lifecycle, unit totals, temporal clustering) |
| Diagonal hatch | WEAKLY_SUPPORTED inferred candidate relation (W1, W2) |
| Pale fill with dotted edge | UNRESOLVED (W1_S60, W3) |
| Grey | unmatched / unclassified / excluded |
| Red scope-warning footer | required full-ledger scope warnings (V3–V6) |

## Manifests

* `reports/m2e_figures/<cycle>/figure_manifest.json` and `case_figure_manifest.json`: for each figure the PNG, the data CSV(s) with sha256 and row counts, and the source datasets (`reports/m2e_data/<cycle>/…`). PNG hashes are informational (renderer-dependent); CSV hashes are the reproducibility anchor.
* `reports/m2e_data/<cycle>/manifest.json`: sha256 of every assembled dataset.
