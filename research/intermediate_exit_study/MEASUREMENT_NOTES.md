# Measurement notes

The fixed protocol, 12 conditions, signal cadence, matching rules and primary
cohort were written before scoring this study. Earlier research had already seen
all dates; this registration does not create an unseen sample.

- The original 32/27 motif partition spans both short and long positions. Only
  9/7 respectively are short covers. A retained contract in M06 has the opposite
  position direction in model 28. These are separate observations, not new motif
  definitions or new original-strategy rules.
- Motif full-flat times can be later than the first reduction in an episode.
  The primary target is the first reduction, not a later neutralization child.
- Original model-28 cover children are grouped using the same 120-second gap and
  intervening-new-short rule for the descriptive comparator. Its own-state replay
  differs in conditioning from this historical-inventory trigger study.
- Baseline pooled fallbacks are explicit even where all training strata exist.
  Baseline/selected-rule feature coverage is reported separately from matching:
  selection coverage uses the actual training-chosen hypothesis on each test
  cycle. These implementation checks do not tune thresholds or outcomes.
- Pre-second book tests multiply stored float32 quote values in float64, as the
  feature builder does. Otherwise the test itself can create small rounding errors.
- Same-second inventory openings/covers cannot be ordered as pre-event decisions.
  All such children remain in the ledger; no within-second future information is
  borrowed. Missing 09:14 bars at the session open remain missing.
- Neither matching controls nor episode/final outcome labeling changes the full
  active-inventory scoring denominator. Control proximity and final labels use
  future records only to define outcomes, never trigger features.
